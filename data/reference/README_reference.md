 Reference Genome

The reference genome `chr22.fa` (~50 MB) is not stored here due to GitHub size
limits.

The file is downloaded automatically inside the Colab notebook:
!wget https://hgdownload.soe.ucsc.edu/goldenPath/hg38/chromosomes/chr22.fa.gz


It is uncompressed and used for all alignments.

This approach ensures full reproducibility without large binary files in GitHub.
