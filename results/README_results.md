# Results Folder (Large Files not Stored on GitHub)

This project generates large alignment files that exceed GitHub's 25MB limit.
These files are stored in Google Colab and automatically generated by the
notebook.

Files NOT included in this repository:
- last_chr22.sam (~22 MB)
- last_chr22_500.sam (~25 MB)
- last_chr22.maf (~28 MB)
- minimap2_week1_chr22.sam (~25 MB)
- ngmlr_chr22.sam (~22 MB)
- combined_all_aligners.csv (~30 MB)
- minimap2_metrics.csv, ngmlr_metrics.csv, last_metrics.csv (>25 MB)

All files are reproducible using the notebook:
👉 `notebooks/week1_week3_complete.ipynb`

To regenerate:
1. Run the Colab notebook.
2. It will download the reference, generate simulated reads,
   run all aligners, and recreate every missing file.

No raw large files are required in GitHub because everything is fully reproducible.
